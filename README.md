# 一箭又一箭

一个使用 Python Tkinter 编写的点击式箭头解谜小游戏。玩家点击箭头，只有箭头朝向棋盘边界的路径上没有其他箭头时，箭头才会飞出并消失。

## 开发环境

- Python 3.9+
- Tkinter（Python 标准库，无需安装第三方包）
- Windows / macOS / Linux

## 运行方法

```bash
python main.py
```

## 游戏操作

1. 在开始界面点击“开始游戏”。
2. 点击没有阻挡的上、下、左、右箭头。
3. 点击被阻挡的箭头会消耗一次失误机会，并显示红色碰撞提示。
4. 清空棋盘后进入下一关；失误次数耗尽后可重新开始本关。
5. 游戏界面底部的“重新开始本关”按钮会恢复初始布局。

## 代码结构

- `Arrow`：保存箭头的行、列和方向。
- `ArrowGame.__init__`：创建窗口、画布和游戏状态。
- `draw_start` / `draw_game` / `show_result`：绘制开始、游戏和结果界面。
- `is_clear_path`：沿箭头方向逐格检查同一行或同一列是否有阻挡。
- `handle_arrow_click`：处理成功消除、碰撞扣分和关卡状态。
- `start_level`：加载关卡并重置失误次数。
